# LipidRT

**Lipid Annotation Curation and Retention Time Prediction for LC–MS Lipidomics**

LipidRT is an R package for improving lipid annotation in LC–MS-based lipidomics by incorporating chromatographic retention time (RT) information.

The package uses the expected chromatographic behaviour of lipid species to:

- **Filter potentially incorrect lipid annotations** based on RT coherence within lipid classes and subclasses.
- **Resolve ambiguous annotations** when multiple lipid candidates are assigned to the same feature.
- **Build RT-based models** from high-confidence lipid annotations.
- **Predict additional lipid annotations**, increasing lipidome coverage while maintaining chromatographic consistency.

LipidRT can be used with lipid annotations generated by tools such as **LipidMS** and **MS-DIAL**.

## Installation

The development version of LipidRT can be installed directly from GitHub:

```r
# Install remotes if necessary
install.packages("remotes")
# Install shiny packages if necessary
install.packages(c("shiny", "shinythemes", "shinyjs", "plotly"))

# Install LipidRT
remotes::install_github("maialba3/LipidRT")
```

Then load the package:

```r
library(LipidRT)
```

## Shiny application

LipidRT includes an interactive **Shiny application** that provides a graphical interface for the LipidRT workflow.

After installing and loading the package, launch the application with:

```r
library(LipidRT)

LipidRTapp()
```

The application will open in your default web browser.

## Workflow

The general LipidRT workflow consists of:

1. Importing lipid annotations obtained from LC–MS lipidomics data.
2. Evaluating the chromatographic coherence of annotated lipids.
3. Filtering annotations inconsistent with the expected RT behaviour.
4. Building RT models using high-confidence annotations.
5. Predicting additional lipid annotations compatible with the observed chromatographic behaviour.

## Input data

LipidRT requires an input file in Excel (.xlsx) or comma-separated values (.csv) format containing the LC-MS features and lipid annotations to be processed.

The input file must contain the following columns:

- mz: Mass-to-charge ratio (m/z) of the detected feature.
- RTsec or RTmin: Chromatographic retention time expressed in seconds (RTsec) or minutes (RTmin). Only one of these columns is required.
- lipidname: Lipid annotation assigned to the feature.
- adduct: Ion/adduct associated with the lipid annotation.

* The lipidname and adduct columns must be present in the input file, but their values can be empty for unannotated features.

### Unannotated features

The input file can include unannotated LC-MS features for which only the mz and retention time (RTsec or RTmin) values are available. For these rows, lipidname and adduct should be left empty.

LipidRT uses the available lipid annotations to evaluate their chromatographic consistency and build RT-based models. Unannotated features can then be evaluated as potential candidates for new lipid annotations based on their m/z and their compatibility with the expected chromatographic behaviour.

Therefore, including unannotated features in the input file allows LipidRT to increase lipidome coverage beyond the initial set of annotations.
